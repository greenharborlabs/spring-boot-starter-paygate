## Decisions
- Implement one ordered direct-vendor evidence chain, extending the mandatory gate registry so an integrity-only run cannot satisfy T7. Separate missing prerequisites from disproved capability and preserve partial evidence on either outcome.
- Use the authorized single 10-sat payment for both normal settlement proof and deliberate loss of the complete dispatch response followed by same-tab reload. Instrument the public dispatch boundary across reload, suppress delivery of its result rather than simulate settlement, recover via supported activity replay, and assert exactly one dispatch. Keep this direct proof distinct from a real Paygate 402-to-200 flow (T8).
- Declare the live workload before spending: one paid target plus two explicitly authorized unpaid 10-sat receive entries for a small sequential history workload, no funded bulk traffic. Record actual rank, age, counts, lookup path, window and scan limits; deterministic tests cover large/page/scan boundaries. Additional invoice creation requires explicit operator authorization; no undeclared workload or retention-duration claim. The implemented live workload is sequential, not live concurrency proof; T5 synthetic concurrent-pagination evidence remains separate.
- Restart through a verified dedicated lifecycle controller, then construct a fresh client/mapper and reconstruct from persisted activity using the payment hash only. Retain original fields solely as comparison expectations, never reconstruction inputs.
- Inject one reversible dependency outage through an owned endpoint-scoped fault harness, not a machine-wide firewall or public-service disruption. Measure actual readiness during the fault; do not assume readiness reflects dependency availability. The request-specific affected-operation outage matrix remains T8. Bound all phases, RPC calls, browser settlement (120 seconds), unlock waits, child processes, and restoration.
- Update existing setup/appendix/manifest only for T7 operation and verified findings, synchronizing manifest acceptance pins when needed. No T9-wide promotion report or approval is implied.
