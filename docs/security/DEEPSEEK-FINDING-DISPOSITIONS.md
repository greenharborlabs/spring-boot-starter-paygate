## Status rules

- `planned` records a chosen path but is not evidence that a control has been implemented or a
  command has passed.
- `implemented` requires the cited control to exist but still requires the listed regression
  evidence.
- `verified` requires a cited, executed command record in the release validation evidence.
- `accepted` is allowed only for an approved, documented inherent or monitored risk with a live
  objective review trigger.
