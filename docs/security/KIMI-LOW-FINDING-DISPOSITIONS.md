## Advancement rules

Only a successful current-revision evidence record may advance a row to `verified`. Only a named
security or release reviewer, UTC date, and reviewed evidence reference may advance it to `approved`.
The validator deliberately rejects invented evidence, placeholders, marker disclosures, and any
unapproved accepted limitation.
